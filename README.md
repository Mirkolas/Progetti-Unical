# Progetti Universitari - UNICAL

Questa repository contiene una raccolta dei progetti sviluppati durante il mio percorso universitario.

## Progetti inclusi

- EasyHome → Applicazione web per gestione immobili
- Schedly → Sistema di gestione attività e pianificazione
- Eventra → Applicazione mobile per eventi
- Progetti Java → Applicazioni desktop e giochi

## Tecnologie utilizzate
- Java
- Spring Boot
- Android (Kotlin)
- HTML, CSS, JavaScript
- MySQL

## Note
Ogni cartella contiene un progetto indipendente con il proprio codice sorgente.
